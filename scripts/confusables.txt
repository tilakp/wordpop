# "word = short sense". build_db.py loads this into the confusables table.

canvas = a strong cloth ; canvass = to seek votes or opinions
capital = a city; money; upper-case letter ; capitol = a legislative building
censor = to suppress content ; censure = to criticize formally ; sensor = a detecting device
cite = to quote as evidence ; site = a place ; sight = vision, something seen
climactic = of a climax ; climatic = of climate
complement = to complete or go well with ; compliment = to praise
comprise = to consist of ; compose = to make up
connote = to suggest beyond the literal ; denote = to indicate literally

defuse = to make less dangerous ; diffuse = to spread out
desert = a dry region; to abandon ; dessert = a sweet course
discreet = careful, tactful ; discrete = separate, distinct
disinterested = impartial ; uninterested = not interested

eminent = distinguished ; imminent = about to happen ; immanent = inherent

envelop = to wrap around (verb) ; envelope = a paper cover for a letter
everyday = ordinary (adjective) ; every day = each day
exalt = to praise highly ; exult = to rejoice
farther = at a greater physical distance ; further = additional; to a greater degree
faze = to disconcert ; phase = a stage
fewer = for things you can count ; less = for amounts you cannot count
flair = natural talent ; flare = a sudden flame; to widen

flounder = to struggle clumsily ; founder = to fail or sink
forego = to go before ; forgo = to do without
foreword = an introduction to a book ; forward = toward the front
formally = in a formal way ; formerly = previously
gibe = a taunt ; jibe = to agree; to change a sail's tack
grisly = gruesome ; grizzly = grey; a kind of bear

hoard = a stock saved away ; horde = a large crowd
hone = to sharpen ; home = to move toward a target, as in home in
historic = important in history ; historical = of or about the past
imply = to suggest (the speaker does this) ; infer = to conclude (the listener does this)
incidence = the rate of occurrence ; incidents = events
ingenious = clever, inventive ; ingenuous = innocent, naive
its = belonging to it ; it's = it is or it has
lay = to put something down (takes an object) ; lie = to recline (no object)
lead = to guide; a metal ; led = past tense of lead
loath = reluctant (adjective) ; loathe = to hate (verb)
loose = not tight ; lose = to misplace; to fail to win
mantel = a shelf above a fireplace ; mantle = a cloak; a role taken on
militate = to work against ; mitigate = to make less severe
moral = a lesson; ethical ; morale = confidence and spirit
naval = of a navy ; navel = the belly button
nauseated = feeling sick ; nauseous = causing sickness
palate = the roof of the mouth; taste ; palette = a board for paints ; pallet = a platform for goods
passed = went past (verb) ; past = gone by; beyond
peak = a top ; peek = a quick look ; pique = to provoke interest or resentment
pedal = a foot lever ; peddle = to sell
perquisite = a perk ; prerequisite = a requirement
persecute = to harass or oppress ; prosecute = to take legal action against
personal = private, individual ; personnel = staff
pore = to study closely, as in pore over ; pour = to make liquid flow
precede = to come before ; proceed = to go on
prescribe = to recommend or order ; proscribe = to forbid
principal = main; head of a school ; principle = a rule or belief
rack = to strain, as in rack your brains ; wrack = wreckage, as in wrack and ruin
reign = to rule ; rein = a strap to control a horse ; rain = water from clouds
respectfully = with respect ; respectively = in the order given
sensual = of physical pleasure ; sensuous = pleasing the senses
stationary = not moving ; stationery = writing materials
than = for comparisons ; then = at that time; next
their = belonging to them ; there = in that place ; they're = they are
tortuous = full of twists ; torturous = involving torture
to = toward ; too = also; excessively ; two = the number 2
vain = conceited; futile ; vane = a blade turned by wind ; vein = a blood vessel
waive = to give up a right ; wave = to move the hand
weather = the state of the atmosphere ; whether = if
who's = who is or who has ; whose = belonging to whom
your = belonging to you ; you're = you are
enquire = to ask (British) ; inquire = to ask; to investigate

bear = to carry; an animal ; bare = uncovered

cache = a hidden store ; cachet = prestige
coarse = rough ; course = a route; a series of lessons

enormity = great wickedness ; enormousness = great size

lightening = making lighter ; lightning = an electric flash in the sky
literally = actually, exactly ; figuratively = not literally; as a metaphor
ordinance = a law ; ordnance = military supplies
populace = the people ; populous = densely populated
reticent = reserved, quiet ; reluctant = unwilling
right = correct; a privilege ; rite = a ceremony ; write = to form words
simple = easy ; simplistic = oversimplified

taught = past tense of teach ; taut = pulled tight
troop = a group of soldiers ; troupe = a group of performers

wreak = to cause damage, as in wreak havoc ; reek = to smell strongly
